# Reality Engine APEX v10 — Product Architecture

## North star
One operating system for project delivery + field reality + digital twin.

## UX rule
Operational screens contain only actions required now. Future technology lives in APEX Intelligence / Future Lab and is not mixed into daily workflows.

## Device strategy
- iPhone: touch-first Field Mode, bottom navigation, one action per step, large targets.
- Windows/Desktop: expanded navigation, dense data views, keyboard shortcuts, multi-pane Digital Twin.
- Tablet: adaptive two-column layout.
- 320px minimum content width, no horizontal scrolling in operational screens.

This follows responsive/adaptive principles documented by Microsoft Fluent 2, including reflow, resize, show/hide and re-architect patterns.

## Capture workflow
1. Select project.
2. Place 4 RCPs.
3. Assign true XYZ.
4. Print A4 target at 100%.
5. Mount flat and rigid.
6. Open iPhone capture app via HTTPS Universal Link.
7. App recognizes RCP centers.
8. User scans full space.
9. App returns signed capture package.
10. Server computes robust 7-parameter transform.
11. Independent check validates result.
12. Human approves publication.
13. Digital Twin revision is created.
